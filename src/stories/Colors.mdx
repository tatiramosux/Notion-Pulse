## Regras de uso

| Cor | Onde usar | Onde NÃO usar |
|---|---|---|
| **Lime `#C8FF00`** | Botão CTA principal, progress bar, preços | Texto corrido, ícones decorativos |
| **Cyan `#00C8FF`** | Headings, links, botão Back, step indicators | Fundos de página inteiros |
| **Navy `#071C3A`** | Fundo de página, texto em cards brancos | Texto sobre navy (sem contraste) |
| **Branco `#FFFFFF`** | Cards, texto sobre navy, forms | Fundo de página (não é dark-first) |
| **Light Blue `#CCF0FF`** | Seções de features (marketing), email | UI interativa, forms |
