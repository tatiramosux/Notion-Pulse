# Color System

CarBrain usa **três cores de marca** com escala tonal de 0 a 100. Cada cor começa em branco puro (0) e termina na cor base saturada (100), interpolada linearmente em RGB.

As escalas são expostas como CSS variables (`--color-cb-navy-50`) e disponíveis como classes Tailwind (`bg-cb-navy-50`, `text-cb-cyan-30`, `border-cb-lime-70`).

---

## Navy — `#071C3A`

Superfície base de toda a UI. Fundos de página, texto sobre cards brancos, botões outline.

**Tokens semânticos usando a escala Navy:**

| Token | Valor | Uso |
|---|---|---|
| `--background` | `navy-100` `#071C3A` | Fundo de página |

| `--muted-foreground` | `navy-50` `#838D9C` ≈ | Texto auxiliar, placeholders |
| `--card-foreground` | `navy-100` | Texto sobre cards brancos |

## Campos (Input fields)

Todos os inputs são **sempre brancos** — `#FFFFFF` — independente da superfície.

| Estado | Background | Texto | Borda | Placeholder |
|---|---|---|---|---|
| Default | `#FFFFFF` | `navy-100` | `rgba(7,28,58,0.2)` | `navy-40` |
| Focus | `#FFFFFF` | `navy-100` | `cyan-100` (ring) | — |
| Disabled | `#FFFFFF` at 50% | `navy-40` | — | — |

## Regras de uso da escala

```
cb-navy  0–30  → tints claros para fundos de seção light
cb-navy  40–60 → texto auxiliar, ícones secundários
cb-navy  70–90 → texto em superfícies claras
cb-navy  100   → fundo de página (--background)

cb-cyan  0–30  → backgrounds de destaque muito sutil
cb-cyan  40–70 → hover states, destaques suaves
cb-cyan  80–90 → links interativos
cb-cyan  100   → headings, step labels, botão Back (--secondary)

cb-lime  0–30  → feedback de sucesso muito sutil
cb-lime  40–70 → hover/active states do botão CTA
cb-lime  80–90 → estados intermediários
cb-lime  100   → CTA principal, progress bar (--primary)
```
