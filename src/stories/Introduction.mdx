# CarBrain Design System

Biblioteca de componentes oficial do **CarBrain** — "The Smartest Way to Sell Your Damaged Car."

> Built on Next.js 15 · TypeScript · Tailwind CSS 4 · shadcn/ui · Storybook 10

---

## Princípios de design

| Princípio | Aplicação |
|---|---|
| **Dark-first** | Navy profundo `#071C3A` como superfície base em toda a UI |
| **Two-accent system** | Lime `#C8FF00` para CTAs · Cyan `#00C8FF` para headings e links |
| **Pill everything** | Botões e inputs 100% arredondados — sem arestas |
| **White card on dark** | Cards brancos flutuam sobre o navy — contraste máximo |
| **Trust & urgency** | Linguagem direta, ofertas garantidas, zero haggling |

---

## Stack

| Tecnologia | Versão | Função |
|---|---|---|
| Next.js | 15+ (App Router) | Framework full-stack |
| TypeScript | strict | Tipagem |
| Tailwind CSS | 4 | Tokens via CSS variables |
| shadcn/ui | latest | Primitivos de UI |
| Storybook | 10 | Documentação & vitest |
| Paytone One | Google Fonts | Display headings |
| Nunito Sans | Google Fonts | Body & UI text |

## Anatomia do produto

```
Landing Page (dark navy hero)
├── Nav — logo + links + "Get an offer" lime pill
├── Hero — Paytone One heading cyan, lime CTA
├── Inline form — ZIP | YEAR | MAKE | MODEL | TRIM (white pill row)
└── CTA — "Get an Offer Now" (lime, pill, bold)

Step Flow (dark navy + white card)
├── Header bar — vehicle + zip info
├── Step card (white surface)
│   ├── Progress bar — lime fill, slim
│   ├── Step X of 10 + section label (cyan)
│   ├── Question — bold dark navy
│   ├── Options — Yes / No (outline pill buttons)
│   └── Navigation — Back (cyan) · Next (lime)
└── Offer card — price in bold, "Accept Your Offer!" lime CTA
```

## Padrões de uso

### CTA primária (lime)
```tsx
<Button variant="default" size="lg">Get an Offer Now</Button>
```

### Botão de navegação Back (cyan)
```tsx
<Button variant="secondary">← Back</Button>
```

### Opções de escolha (outline)
```tsx
<Button variant="outline" size="lg">Yes</Button>
<Button variant="outline" size="lg">No</Button>
```

### Step progress
```tsx
<div className="flex justify-between mb-2">
  <span className="text-secondary font-bold">Step 2 of 10</span>
  <span className="text-secondary text-sm">Ownership</span>
</div>
<Progress value={20} className="h-1.5" />
```

### Card branco sobre navy
```tsx
<Card className="bg-card text-card-foreground rounded-2xl">
  ...
</Card>
```
