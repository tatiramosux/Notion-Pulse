# Typography

O Notion Pulse usa a família **Geist** (sans e mono) via Next.js Google Fonts, injetada como variáveis CSS.

## Variáveis CSS

| Variável | Fonte | Uso |
|---|---|---|
| `--font-geist-sans` | Geist Sans | Textos gerais, UI |
| `--font-geist-mono` | Geist Mono | Código, valores numéricos |
