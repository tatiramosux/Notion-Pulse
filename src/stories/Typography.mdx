# Typography

CarBrain usa duas fontes — uma display bold para impacto e uma sans arredondada para legibilidade.

---

## Famílias

| Variável CSS | Fonte | Uso |
|---|---|---|
| `--font-paytone-one` | **Paytone One** | H1, H2, H3, H4 — headlines de impacto |
| `--font-nunito-sans` | **Nunito Sans** | Body, UI, labels, buttons, descriptions |
| `--font-geist-mono` | Geist Mono | Código, valores técnicos |

## Pesos utilizados

| Peso | Uso |
|---|---|
| **300 Light** | Placeholders, helper text secundário |
| **400 Regular** | Body text geral |
| **600 SemiBold** | Labels, nav links |
| **700 Bold** | Questions, emphasis, step labels |
| **800 ExtraBold** | Prices, key numbers |
| **900 Black** | Dollar amounts, offer values |

---

## Convenções

- **Headings** (H1–H4) → sempre `font-heading` (Paytone One)
- **Field labels** → `text-xs font-bold uppercase tracking-widest`
- **Cyan highlight** → `text-secondary` (electric cyan) — seções "First, let's get…"
- **White body** → `text-foreground` — perguntas e descrições
- **Muted text** → `text-muted-foreground` — helpers e placeholders
